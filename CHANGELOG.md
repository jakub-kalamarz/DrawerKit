# Changelog

All notable changes to DrawerKit are documented here. The project follows Semantic Versioning.

## [1.0.0] - 2026-08-16

### Added

- Interactive leading and trailing SwiftUI drawers
- Edge reveal, drag-to-close, tap-to-dismiss and binding-driven presentation
- Adaptive geometry, device-aware corners, shadows, scrim and haptic configuration
- Right-to-left layout, Reduce Motion and VoiceOver escape support
- Unit tests, UI tests, DocC documentation and a standalone example app
